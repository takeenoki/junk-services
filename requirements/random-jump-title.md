## 概要
- 歴代のジャンプ連載作品からランダムで一つ表示するサービスを作成する

## サービス名
- random-jump-title

## サービス構成
- Webページ
  - ボタン押下でAPIからジャンプタイトルを表示
- API
  - GETで週刊少年ジャンプの歴代のタイトル等の情報をランダムに返すAPI
  - DBはD1を使用
- ツール
  - 週刊少年ジャンプ連載作品の一覧をスクレイピングし、SQL化するツール

## Webページ
- タイトル
  - ジャンプの歴代作品をランダムで表示
- ボタン押下すると情報を表示

## データベース
- テーブル名
  - jump-titles
- カラム　※物理名は任意に付けること
  - 作品名
  - 作品URL
  - 作者名
  - 作者URL
  - 開始号
  - 終了号

## ツール設計概要
- Wikiページ（https://ja.wikipedia.org/wiki/%E9%80%B1%E5%88%8A%E5%B0%91%E5%B9%B4%E3%82%B8%E3%83%A3%E3%83%B3%E3%83%97%E9%80%A3%E8%BC%89%E4%BD%9C%E5%93%81%E3%81%AE%E4%B8%80%E8%A6%A7）をスクレイピングし、DBに投入するためのSQLファイル(DML)を生成する
- スクレイピング対象
  - 作品一覧、の項のテーブル（現在のDOMのIDはmw-g）
- スクレイピングのマッピング（データ:Webページの項目）
  - 作品名 : 作品名
  - 作品URL : 作品名がアンカーの場合のURL。アンカーでない場合はnull
　- 作者名 : 作者（作画）
  - 作者URL : 作者（作画）がアンカーの場合のURL。アンカーでない場合はnull
  - 開始号 : 開始
    - 入力フォーマットはYYYY.GG。YYYY年GG号に変換（GGが0始まりの場合は0を除く）
  - 終了号 : 終了 
    - 入力フォーマットはYYYY.GG。YYYY年GG号に変換（GGが0始まりの場合は0を除く）

- DMLの配置ディレクトリはcloudflareの標準的なディレクトリ構成とする
- DMLファイルの命名はrandom-jump-title-data.sqlとする
- DMLファイルの世代管理は行わない
- 不要なサーバー負荷をかけることを避けるため、ツールの定期実行は行わない。必要に応じて手動実行し、SQLを適用する形とする。
- DMLファイルはリラン可能な作りとする
