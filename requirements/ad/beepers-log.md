# BEEPERS ログ追加
## 1. 概要
- BEEPERSのボタン押下イベント時にログを出力する。

## 2. ログ出力仕様
- BEEPERSの操作ログは、以下の形式で出力する。
### 2.1 ログフォーマット
- BEEPERS [INFO] {操作種別} {ボタン番号}
### 2.2 各項目の定義
| 項目 | 内容 |
| - | - |
| BEEPERS |サービス識別値。固定値 |
| [INFO] | ログレベル。固定値 |
| 操作種別 | SAMPLE:試聴、PUT:音の投稿 |
| ボタン番号 | 捜査対象のボタン番号 |

## 3. 仕様詳細
- ボタンを押下したタイミングでログを出力する。長押し時にボタンを離した際にはログを出力しない。
- 従ってボタンを押した長さはログに出力しない。

## 4. 開発ルール
- ブランチはbeepers-logで行う。
